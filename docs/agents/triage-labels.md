# 分诊标签

处理 Issue 分类时使用以下角色；先查询仓库实际标签，尚未配置时不要声称标签已存在。

| 默认标签        | 含义                         |
| --------------- | ---------------------------- |
| needs-triage    | 待评估                       |
| needs-info      | 等待补充信息                 |
| ready-for-agent | 范围和验收明确，可交给 Agent |
| ready-for-human | 需要人工处理                 |
| wontfix         | 已决定不实施                 |

新项目如采用其他标签名，在此维护映射，不复制其他产品专用标签。
